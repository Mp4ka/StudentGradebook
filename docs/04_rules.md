# Правила оценивания и расчётов

Правила согласованы до начала разработки: разработчик, QA и аналитик должны считать
одинаково. Реализация — `app/src/main/java/ru/college/gradebook/domain/GradeMath.kt`,
проверка — `ручные проверки` (9 проверок).

## 1. Шкала и учёт оценок

* Пятибалльная шкала, целые значения 2, 3, 4, 5. Значение 1 и дробные оценки запрещены
  на уровне модели (`Grade.init`) и интерфейса (выбор из четырёх вариантов).
* В базовой версии все оценки равноправны, весов по видам работ нет. Веса — отдельное
  согласованное расширение.
* Пересдача оформляется новой записью с комментарием; устаревшую запись можно удалить.
* Оценка 2 учитывается в среднем так же, как остальные.

## 2. Средний балл

Средний балл по дисциплине — среднее арифметическое её оценок:

```
avg = Σ value / n
```

Общий средний балл — среднее арифметическое всех оценок по всем дисциплинам, а не
среднее из средних по предметам.

Если оценок нет, средний балл не определён: `null`, в интерфейсе «—» и пояснение.
Деления на ноль нет.

Округление и вывод едины во всём приложении: половина вверх, два знака, лишние нули
отбрасываются, разделитель — запятая.

| Случай | Значение | Вывод |
|---|---|---|
| 5, 4, 3, 5 | 4,25 | `4,25` |
| 5, 4, 5, 4, 3, 5 | 4,3333… | `4,33` |
| 5, 4, 4 | 4,3333… | `4,33` |
| 5, 5, 5 | 5,0 | `5` |
| нет оценок | — | `—` |

## 3. Целевой балл

Пользователь задаёт цель `T` (2…5). Требуемая следующая оценка:

```
x = ceil(T × (n + 1) − S)
```

где `n` — количество оценок, `S` — их сумма.

Интерпретация:

* `x > 5` — цель недостижима одной оценкой; показывается пояснение, недопустимое
  значение не выводится;
* `x ≤ 2` — цель уже достигнута; выводится сообщение, а не требование получить 1 или 2;
* иначе — конкретная оценка `x`.

| S | n | T | T × (n+1) − S | Ответ |
|---|---|---|---|---|
| 26 | 6 | 4,20 | 3,4 | нужна оценка 4 |
| 26 | 6 | 4,40 | 4,8 | нужна оценка 5 |
| 26 | 6 | 4,60 | 6,2 | цель недостижима одной оценкой |
| 26 | 6 | 4,00 | 2,0 | цель уже достигнута |
| 0 | 0 | 4,20 | 4,2 | нужна оценка 5 |
| 17 | 4 | 4,50 | 5,5 | цель недостижима одной оценкой |

## 4. Граничные случаи

| Ситуация | Ожидаемое поведение |
|---|---|
| Нет ни одной оценки | Средний «—», цель = `ceil(T)`, без деления на ноль |
| Одна оценка | Средний равен этой оценке, формат «5» без «,00» |
| Все оценки 5 | Средний 5; цель 5 — «цель уже достигнута» |
| Оценка вне 2…5 | Сохранение блокируется, поле подсвечено, текст ошибки |
| Пустое название дисциплины | Кнопка сохранения неактивна, поле обязательное |
| Будущая дата | Разрешена с предупреждением |
| Удаление дисциплины с оценками | Диалог с количеством оценок, затем каскадное удаление |
| Поворот экрана при вводе | Введённые данные сохраняются |

## 5. Почему так

* Единая функция расчёта исключает расхождение округления между экранами — это главный
  риск четвёртого спринта.
* `ceil` вместо простого вычитания нужен потому, что оценка целая: 4,8 балла невозможно,
  поэтому требуется 5.
* Отказ от «среднего из средних» выбран потому, что он искажает картину при разном
  количестве оценок по предметам: предмет с двумя оценками не должен весить столько же,
  сколько предмет с десятью.
