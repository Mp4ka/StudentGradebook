# Аналитика: фильтры, сортировка и динамика

Спринт 4 добавляет к журналу фильтры и сортировку, а к приложению — экран динамики
среднего балла по месяцам.

## 1. Фильтры журнала

| Фильтр | Значения | Поведение |
|---|---|---|
| Вид работы | Все, КР, ПР, ЛР, ОТВ, ТЕСТ | чипы под сводкой, выбор одного вида |
| Период | произвольный диапазон дат | календарь MaterialDatePicker, границы включаются |
| Сортировка | сначала новые / старые, по убыванию / возрастанию оценки | меню на кнопке «Сортировка» |

Фильтр и сортировка живут в доменной модели `GradeFilter`:

```kotlin
data class GradeFilter(
    val workType: WorkType? = null,
    val period: Period? = null,
    val sort: GradeSort = GradeSort.DATE_DESC
) {
    fun matches(grade: Grade): Boolean
    fun apply(grades: List<Grade>): List<Grade>
}
```

Логика вынесена из Activity, поэтому проверяется обычными проверкиами
(`ручные проверки`, 8 тестов): вид работы, период с включёнными границами, их
комбинация, четыре порядка сортировки и пустой результат.

Когда фильтр активен, под кнопками появляется строка «По фильтру: 4,20 · 3 оценки»:
видно и средний балл выборки, и её размер. Общий средний балл дисциплины при этом не
меняется — он всегда считается по всем записям.

Если по условиям ничего не найдено, показывается отдельное состояние «По фильтру
ничего нет» с кнопкой «Сбросить фильтр», а не пустой экран.

## 2. Сортировка

| Режим | Порядок |
|---|---|
| Сначала новые | по дате убыв., при равной дате — по id убыв. |
| Сначала старые | по дате возр., при равной дате — по id возр. |
| По убыванию оценки | по значению убыв., при равенстве — сначала новые |
| По возрастанию оценки | по значению возр., при равенстве — сначала новые |

## 3. Динамика по месяцам

Экран S5 (`DynamicsActivity`) показывает:

* средний балл и количество оценок по выбранной дисциплине или по всем сразу;
* столбчатый график среднего балла по месяцам (собственный `MonthlyChartView`);
* подпись «среднее арифметическое по записям, без весов»;
* лучший месяц и месяц с просадкой.

Расчёт — `Analytics.monthly(grades)`: группировка по `YearMonth`, среднее через
`GradeMath.average`, хронологический порядок. Месяцы без оценок не появляются и не
искажают график.

Шкала графика зафиксирована от 2 до 5, чтобы столбцы были сравнимы: средний балл 4,0
всегда на одной высоте независимо от набора данных. Цвет столбца: зелёный при 4,5+,
янтарный при ниже 3,5, иначе основной.

## 4. Проверки

| Проверка | Инструмент | Результат |
|---|---|---|
| Фильтры по виду работы и периоду | `ручные проверки`, 8 тестов | пройдено |
| Сортировка по дате и значению | `ручные проверки` | пройдено |
| Месячная группировка и средние | `ручные проверки`, 3 теста | пройдено |
| Лучший/худший месяц, пустой список | `ручные проверки` | пройдено |
| Валидация формы | `ручные проверки`, 6 тестов | пройдено |
| Расчёты среднего и цели | `ручные проверки`, 9 проверок | пройдено |
| Демо-набор | `ручные проверки`, 3 теста | пройдено |

Итого ручные проверки.

## 5. Ограничения

* Фильтр по виду работы — одиночный выбор; множественный выбор останется на спринт 5,
  если понадобится.
* Веса работ не учитываются: приложение прямо пишет, что показывает среднее
  арифметическое по записям.
* Экран динамики не строит прогноз — калькулятор целевого балла в спринте 5.
