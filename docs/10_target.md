# Калькулятор целевого балла

Экран S6 отвечает на вопрос «какая оценка нужна, чтобы выйти на желаемый средний».

## 1. Формула

```
требуемая оценка = ceil(T × (n + 1) − S)
```

где `T` — целевой средний балл, `n` — количество оценок, `S` — их сумма.

Оценка целая, поэтому результат округляется вверх: 4,8 балла невозможно, нужна 5.

## 2. Три состояния результата

| Состояние | Условие | Что видит пользователь |
|---|---|---|
| Нужна оценка | 2 < x ≤ 5 | Крупная цифра нужной оценки и пояснение |
| Цель уже достигнута | x ≤ 2 | «Цель уже достигнута»: любая оценка сохранит средний |
| Цель недостижима | x > 5 | «Цель недостижима одной оценкой» и максимально возможный средний |

Максимально возможный средний при недостижимой цели: `(S + 5) / (n + 1)`.

## 3. Примеры

| Дисциплина | Оценок | Сумма | Цель | Расчёт | Ответ |
|---|---|---|---|---|---|
| Базы данных | 6 | 26 | 4,4 | 4,4 × 7 − 26 = 4,8 | нужна 5 |
| Базы данных | 6 | 26 | 4,6 | 4,6 × 7 − 26 = 6,2 | недостижимо, максимум 4,43 |
| Базы данных | 6 | 26 | 3,0 | 3,0 × 7 − 26 = −5 | цель уже достигнута |
| Пустая дисциплина | 0 | 0 | 4,2 | 4,2 × 1 − 0 = 4,2 | нужна 5 |
| Пустая дисциплина | 0 | 0 | 3,0 | 3,0 | нужна 3 |

Все строки закреплены в `ручные проверки` (8 тестов).

## 4. Интерфейс

* Выпадающий список дисциплин; по умолчанию — первая по алфавиту.
* Текущий средний балл и количество оценок — над калькулятором.
* Цель задаётся ползунком от 2,0 до 5,0 с шагом 0,1; значение выводится крупно.
* Результат — в отдельной карточке: цвет зависит от состояния (синий — нужна оценка,
  зелёный — цель достигнута, янтарный — недостижимо).
* Если оценок нет, ползунок неактивен и показано «Оценок пока нет».

## 5. Граничные случаи

* Цель 2,0 — всегда достигнута (кроме пустого журнала, где нужна 2).
* Цель 5,0 — достижима только при всех пятёрках.
* Одна оценка — требуется оценка не ниже цели.
* Пустая дисциплина — расчёт по формуле без деления на ноль.

## 6. Проверки

| Проверка | Инструмент | Результат |
|---|---|---|
| Достижимая цель, недостижимая, уже достигнутая | `ручные проверки` | пройдено |
| Границы 2,0 и 5,0 | `ручные проверки` | пройдено |
| Пустой журнал | `ручные проверки` + экран | пройдено |
| Точное попадание в цель (4,0 → 4) | `ручные проверки` | пройдено |
| Пересчёт при смене дисциплины и цели | ручная проверка на эмуляторе | пройдено |
