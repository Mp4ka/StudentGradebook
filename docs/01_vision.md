# Паспорт приложения «Успеваемость»

**Проект:** личный кабинет успеваемости студента (командный проект, 6 спринтов × 6 часов).
**Платформа:** Android, Kotlin, minSdk 26, targetSdk 37, compileSdk 37.
**Хранение:** локальная база Room поверх SQLite (спринт 2).
**Архитектура:** Activity + ViewModel + Repository, один модуль `app`.

## 1. Назначение

Студент ведёт оценки в бумажном журнале или таблице и считает средний балл вручную.
Приложение собирает оценки в одном месте, группирует их по дисциплинам, автоматически
считает средние баллы и показывает, какая оценка нужна за следующую работу, чтобы выйти
на желаемый результат.

Приложение отвечает на три вопроса:

1. Какой у меня средний балл?
2. Что стоит за этим баллом по каждому предмету?
3. Что нужно получить, чтобы выйти на цель?

## 2. Аудитория и сценарий использования

Аудитория — студент колледжа или вуза, который сам ведёт свои оценки. Данные вводятся
вручную и хранятся только на устройстве: приложение не заменяет электронный журнал и не
претендует на юридическую точность.

Основной сценарий: открыть приложение → увидеть средний балл → открыть предмет →
добавить или исправить оценку → проверить, как изменился средний балл.

## 3. Границы MVP

| Входит в MVP | Не входит (бэклог) |
|---|---|
| Главный экран: общий средний балл, количество оценок, сводка по дисциплинам | Авторизация, профили, несколько студентов на устройстве |
| Список дисциплин с преподавателем и средним баллом | Сервер, синхронизация, облачное резервное копирование |
| Журнал оценок: дата, вид работы, значение, комментарий | Взвешенный средний балл и веса работ |
| Добавление, редактирование и удаление оценки | Экспорт в PDF/Excel, печать, виджеты |
| Средний балл по дисциплине и общий средний балл | Напоминания и уведомления |
| Проверка диапазона 2–5, обязательные поля, пустые состояния | Тёмная тема, планшетная вёрстка, другие языки |
| Фильтры по виду работы и периоду, сортировка | Импорт данных из файлов и журналов |
| Динамика по месяцам и калькулятор целевого балла | Социальные функции, рейтинги, сравнение с группой |

## 4. Приоритеты функций

| Функция | Приоритет | Спринт |
|---|---|---|
| Сводка и список дисциплин | Must | 3 |
| Журнал оценок, добавление и редактирование | Must | 3 |
| Удаление записи с подтверждением | Must | 3 |
| Средние баллы, обработка пустых данных | Must | 4 |
| Фильтры и сортировка | Should | 4 |
| Динамика по периодам | Should | 4 |
| Целевой балл и проверка достижимости | Should | 5 |
| Подсветка дисциплин с низким баллом | Should | 5 |
| Взвешенный балл, сценарный прогноз | Could (после защиты) | — |

## 5. Допущения

* Шкала пятибалльная, оценки целые, допустимы значения 2–5.
* В базовой версии все работы имеют одинаковый вес.
* Пересдача оформляется новой записью, старая может быть удалена студентом.
* Средний балл отображается с двумя знаками после запятой (округление половина вверх).
* Демонстрационные данные: 5 дисциплин, 25 оценок, общий средний балл 4,24.
