# «Успеваемость» — личный кабинет студента

Командный проект: Android-приложение для учёта оценок, расчёта среднего балла и
планирования результата. 6 спринтов по 6 учебных часов, команда из двух человек.

**Статус:** проект завершён (v1.0.0) — реализованы все функции MVP, добавлен
индикатор риска с настраиваемым порогом, 17 тест-кейсов, готова
инструкция пользователя и презентация.

## Что уже есть

* `app/` — Android-проект: главный экран, список дисциплин, журнал оценок, форма оценки
  с валидацией; модели `Discipline`, `Grade`, `WorkType`, расчёты `GradeMath`.
* Слой данных: Room (Entity, DAO, `GradebookDatabase`, конвертеры), репозиторий,
  демонстрационный набор и его идемпотентная загрузка.
* Тестирование ручное: 17 тест-кейсов в docs/TEST_CASES.md, проверки на эмуляторе API 37.
* `docs/` — паспорт, экраны и навигация, 7 сценариев с критериями приёмки, правила
  расчётов, модель данных, устройство хранилища, бэклог и роли, прототипы экранов.
* Отчёты по дням: `docs/Спринт_1_Отчёт_Успеваемость.docx`,
  `docs/Спринт_2_Отчёт_Успеваемость.docx`, `docs/Спринт_3_Отчёт_Успеваемость.docx`,
  `docs/Спринт_4_Отчёт_Успеваемость.docx`.

## Сборка и проверки

Требования: JDK 17+, Android SDK 37, Gradle wrapper из репозитория.

```bash
./gradlew assembleDebug            # APK: app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` содержит путь к SDK и не коммитится.

## Структура

```
app/src/main/java/ru/college/gradebook/
├── MainActivity.kt              — главный экран: данные из Room
├── GradebookApp.kt              — сборка зависимостей и первичное заполнение базы
├── ui/disciplines/              — список дисциплин (S2)
├── ui/journal/                  — журнал оценок и фильтры (S3)
├── ui/dynamics/                 — динамика по месяцам (S5)
├── ui/target/                   — калькулятор целевого балла (S6)
├── ui/edit/                     — форма оценки (S4)
├── data/
│   ├── model/                   — доменные модели
│   ├── db/                      — Entity, DAO, база, конвертеры, демо-данные
│   └── GradebookRepository.kt   — единая точка доступа к данным
└── domain/GradeMath.kt          — средний балл и целевой балл
```

Схема базы экспортируется в `app/schemas/ru.college.gradebook.data.db.GradebookDatabase/1.json`.
